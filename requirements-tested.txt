# CalibDeconv — validated environments

# This is NOT a constraint file for running CalibDeconv, and neither environment
# below is the one in which the original analysis was performed. Use
# requirements.txt for installation; it deliberately keeps broad lower bounds.
# The software versions reported in the manuscript Methods are unchanged.
#
# Two independent environments in which the analyses were re-run from a clean
# checkout. Both are CPython 3.12.10 on Windows.
#
#   Environment A — pandas 2.x   (matches the manuscript's reported versions)
#   Environment B — pandas 3.x   (what requirements.txt resolves to today)
#
# Scope validated in v1.2.2 (v1.2 validated only the coverage scripts):
#   scripts/15_simultaneous_coverage.py      byte-identical outputs
#   scripts/16_gse107572_real_bulk.py        byte-identical outputs
#   scripts/06b_stress_marker5.py            Tier 1 stress  (Figure 4)
#   scripts/06d_stress_tier2_subset.py       Tier 2 stress  (Figure 5)
#   scripts/10_publication_figures.py        Figures 1-5
#   tests/test_stress_dataframe_compat.py    6/6 pass in both environments
#
# Known cross-environment difference, unrelated to any CalibDeconv code:
#   numpy's Generator.binomial stream differs between 2.4.6 and 2.5.3 for some
#   (n, p). apply_low_depth is the only function that draws from it, so the two
#   low_depth_* Tier 1 scenarios differ by at most 3.6e-04 between the
#   environments. The other seven Tier 1 scenarios and all of Tier 2 are
#   bit-identical. Pin numpy if you need low_depth reproduced exactly.
#
# Install one of them with:
#   pip install -r requirements-tested.txt      # environment B, listed below
